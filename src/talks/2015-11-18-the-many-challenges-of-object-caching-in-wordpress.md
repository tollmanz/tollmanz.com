title: "The Many Challenges of Object Caching in WordPress"
date: 2015-11-18
conference: "php[world] 2015"
location: "Washington, DC"
description: "It's no secret that WordPress can be slow and tough to scale. A key ingredient to scaling WordPress is setting up object caching. Object caching reduces the number of heavy database calls that WordPress needs to satisfy web requests. My talk will discuss the many details of how WordPress loads a third-party object cache, the API that developers can use, and design patterns for effective object caching. Finally, I will share my personal experiences in using object caching to help scale enterprise-level WordPress installations."
